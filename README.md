# Md Atiqur Rahman — Animated Resume

A responsive animated resume/portfolio using plain HTML, CSS and JavaScript. No build tools required.

## Files
- `index.html` — content and page structure
- `style.css` — responsive design and animations
- `script.js` — scroll reveals, progress bar, mobile menu and interactive card
- `cv.pdf` — add your own CV PDF with this filename

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
2. Add your CV as `cv.pdf` in the same folder.
3. Replace `https://github.com/` with your actual GitHub profile URL.
4. Review all experience dates, project descriptions and profile links for accuracy.

## GitHub Pages
Upload these files to a GitHub repository. Open **Settings → Pages → Deploy from a branch → main → /(root)** and save.
